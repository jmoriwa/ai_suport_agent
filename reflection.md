# Project Reflection

One design decision I made during troubleshooting was to use Python 3.13 instead of Python 3.14 for both the project and its deployment container. Browser testing exposed asynchronous runtime errors, and investigation showed that the browser tool used a compatibility patch that caused problems under Python 3.14. I updated the project's Python requirement, dependency lock file, and Docker image to use Python 3.13, then verified that a local asynchronous compatibility check passed. This decision prioritized compatibility with the agent's dependencies and kept the local and deployed Python versions consistent.

A concrete challenge was diagnosing why the agent could respond conversationally but could not retrieve Platinum loyalty benefits. Its response mentioned technical difficulties and supplied generic benefits, which did not demonstrate successful knowledge-base retrieval. I inspected the CloudWatch logs and found an AccessDeniedException: the runtime execution role lacked the bedrock:Retrieve permission. I resolved this by adding an IAM policy scoped to the specific knowledge base and repeating the test. The subsequent response returned the documented Platinum benefits. This experience taught me to use tool results and runtime logs as evidence instead of relying on the model's explanation of an error.

For a production environment, I would strengthen authentication and authorization. The application should derive customer identity from an authenticated session rather than trust a customer ID supplied in a request. Refund processing should include eligibility checks, explicit confirmation, and protection against duplicate transactions. I would also improve the agent's instructions so that failed tools produce clear limitations instead of unsupported claims about benefits or website content.

Finally, I would add automated integration tests, structured logging, CloudWatch alarms, and human escalation for unresolved requests. Memory would need retention controls and safeguards against storing inaccurate information. These changes would make the agent more reliable, protect customer data, and help support staff investigate failures.
